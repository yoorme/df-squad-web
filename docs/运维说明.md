## 当前部署架构

| MMR | 3000 | `squad-signup.service` | `squad_signup` | `/opt/squad-signup/.env` | `/opt/squad-signup/uploads` |
| YFD | 3001 | `squad-signup-shuishangyue.service` | `shuishangyue` | `/opt/squad-signup/instances/shuishangyue/.env` | `.../instances/shuishangyue/uploads` |

代码来源：GitHub `yoorme/squad-signup-latest`（push 到 main 触发 Actions 构建并更新 `latest` Release）。

## 日常更新流程

```bash
cd /opt/squad-signup
bash update.sh             # 停主站 → 下载产物 → 迁移主库 → 重启 3000
bash update-instances.sh   # 各实例：迁移实例库 + 重启实例服务（YFD 等）
```

> 注意：只跑 update.sh 的话 YFD 会继续运行旧代码且库结构不迁移——**务必跟跑 update-instances.sh**。

## 关键配置（各 .env）

| 变量 | 说明 |
|---|---|
| `PORT` | 服务端口 |
| `AUTH_COOKIE_NAME` | 会话 Cookie 名，多实例必须互不相同（防互相踢下线） |
| `TRUST_PROXY` | 无反代时必须为 `false`（防伪造头绕过登录限流）；以后挂 Nginx 改 `true` |
| `CRON_SECRET` | 临近提醒定时扫描密钥（systemd timer 使用） |
| `JPUSH_APPKEY` / `JPUSH_MASTER_SECRET` | 极光推送，未配置则推送静默关闭 |
| `TEAM_PREFIX` | 仅首装 seed 使用；日常改前缀请在网站「战队管理」操作 |
| `THEME_FROM_ICON` | 默认开启：网页从战队图标取主色生成 M3 主题；设为 `off` 回退静态蓝色配色。改主题只需换战队图标 |

## 工具链要求（Node 24 / npm 12 / Next 16）

| 项目 | 要求 | 说明 |
|---|---|---|
| Node.js | **≥ 24**（`package.json engines`） | Next.js 16 最低要求 20.9，本项目按 24 验证 |
| npm | 12.x | 12 起有两处影响安装的新默认值，见下 |
| 打包器 | Turbopack（`next dev` / `next build` 默认） | Dockerfile 仍显式用 `--webpack`；本地构建走 Turbopack |

**npm 12 的两处新默认值**（`npm install` 报错或依赖缺失时对照排查）：

1. `allow-remote=none`：镜像站（如 npmmirror）把 tarball 指向其它主机时会被拒绝，
   报 `npm error code EALLOWREMOTE`。仓库根目录已提交 `.npmrc`（`allow-remote=all`）解决；
2. `allow-scripts` 默认拦截依赖的安装脚本（构建日志会列出待批准的包）。
   若 `prisma generate` 未自动执行，先 `npm rebuild @prisma/client`（或
   `npm install-scripts approve prisma`），再手动 `npx prisma generate`。

**Next 16 注意点**：

- `cookies()` / `headers()` / `params` / `searchParams` 已全部异步化（同步访问已移除）；
- `middleware` 更名为 `proxy`（本项目未使用中间件）；
- `next lint` 已移除，`package.json` 的 `lint` 脚本直接用 `eslint`（flat config）；
- `next build` 不再执行 ESLint，需单独跑 `npm run lint`；
- `turbopack.root` 已在 `next.config.ts` 固定为项目目录，避免上层目录锁文件干扰。

## 定时任务

- **临近提醒扫描**：`squad-notify.timer` / `squad-notify-shuishangyue.timer` 每分钟 curl
  `/api/notifications/tick`（带 CRON_SECRET），扫描 24h 内开赛的报名者并推送提醒，PushLog 去重。
- **数据库备份**：`/etc/cron.d/squad-db-backup` 每日 03:17/03:18 用 pg_dump 备份两库到
  `/opt/backups/squad/*.sql.gz`，保留 7 天。

## 会话 Cookie 说明

多实例共用同一 IP，浏览器 Cookie 不区分端口。`AUTH_COOKIE_NAME` 已按实例区分
（`squad_signup_session` / `shuishangyue_session`），此后 MMR 与 YFD 可在同一浏览器同时登录。
（该变更使所有旧会话失效一次，用户需重新登录。）
